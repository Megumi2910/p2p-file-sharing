Understand the system before changing it.

This is a university-scale hybrid peer-to-peer file sharing application. A central tracker tells peers how to find one another; the peers then send file bytes directly over TCP. The central engineering pressure is keeping discovery separate from transfer while proving that every received byte belongs to the intended file.

Current

Stabilized foundation

Sequential transfer, owned staging, atomic publication, bounded admission, phase timeouts, and verified packaging gate established (F-01A–F-07).

Known limits

Deployment boundary

Controlled private-network operation only; R-008 plaintext exposure remains unresolved. Dual Ubuntu VM topology is blocked until VMs are provisioned.

Verified

Local proof gate

Maven reactor verify passes 63 tests; packaged shaded JAR smoke passed; real desktop Swing screenshots captured (F-08A Local).

What “current” means

Claims marked Current are backed by active source or a focused runtime check. Planned means the roadmap describes the behavior but the active protocol does not implement it. Known limit identifies a reproduced defect or a clear gap in the active path. Unverified means the handbook deliberately avoids presenting an instruction or simulation as proof.
